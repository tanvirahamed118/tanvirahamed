# Tanvir Ahamed — Developer Portfolio

React + TypeScript portfolio recreated from the supplied HTML. Tailwind CSS v4 is integrated through its official Vite plugin; custom CSS preserves the source design's precise colors, spacing, layout and animations.

## Requirements
- Node.js 20.19+ or 22.12+
- npm

## Start
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
npm run preview
```

## Update your details
Edit `src/data.ts` to change the contact email, social links, services, projects, stack and process steps. Replace `public/logo.png` to use another logo.

**Background note:** The supplied HTML does not contain a separate photographic background image. It uses a dark background, subtle grid, blurred orange glows and gradient accents. These are recreated in `src/styles.css`.
